Bursa Malaysia Screener

Composite scores, Momentum, Buffett and Rule #1 screens for Main and ACE Market stocks.

Open the screener

iPhone This device

Option 1, install the icon (open this page in Safari):

  1. Tap Download for iPhone below, then Allow.
  2. Open Settings, tap Profile Downloaded, then Install.
Download for iPhone

Option 2, add from Safari: tap the Share button on this page, then Add to Home Screen. The icon opens the screener directly.

iOS shows the profile as "Not Verified" because it isn't signed by a company. It contains only the Home Screen icon and link. Remove it any time in Settings → General → VPN & Device Management.

Mac This device

  1. Download the app below and double-click the zip to unzip it.
  2. Drag Bursa Screener into your Applications folder.
  3. The first time, right-click it and choose Open, then Open again. If macOS still refuses, go to System Settings → Privacy & Security → Open Anyway.
  4. Drag it from Applications onto the Dock.
Download for Mac

macOS asks because the app isn't from the App Store. It only opens the screener in your browser.

Windows This device

Open the screener in Chrome or Edge, then use the browser menu: Cast, save and share → Install page as app (Chrome) or Apps → Install this site as an app (Edge).

The screener is private, so sign in to Claude when it opens. Mechanical screen on published figures, not financial advice.
